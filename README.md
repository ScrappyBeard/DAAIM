# Dynamic Architecture AI Map (DAAIM) — Anonymized Public Demo v2

Self-contained, 100% offline interactive prototype illustrating how an enterprise can unify CMDB topology (ServiceNow), documentation (Confluence & SharePoint), infrastructure inventory (Infralens), network flow approvals (Illumio / Tufin), security/cyber governance (Wiz, Brinqa, ThreatModeler, Archer), and Agentic AI into one living architecture map.

> **Note:** All application names, CI IDs, IPs, people, incidents, and documents are synthetic European (Amsterdam & Dublin) sample data for concept demonstration.

## Quick Start (No Server or Internet Required)

1. Unzip this archive.
2. Double-click **`index.html`** to open in Chrome, Edge, Firefox, or Safari.
3. All dependencies (`assets/tailwindcss.min.js`) are bundled locally — zero external CDN requests, with a working **Dark Mode / Light Mode** toggle in the header.

## Highlights in v2

- **Executive Dashboard:** KPIs, Architecture Health meters, interactive Estate Domain Map, Top AI Recommendations, Risk Hotspots, Quick Ask AI box, and Report Export.
- **Human-in-the-Loop (HITL) Verification:** Amber `?` badges for missing docs/owners, inline Inspector verification controls, AI-inferred edge approval (`Approve Edge` -> solid green `Human Approved`), and centralized `Governance & HITL` queue + audit trail.
- **Hosted On (Box Outline) Legend:** Clickable color-coded node borders for **Equinix**, **Edge**, **AWS**, **Azure**, and **GCP** across **Amsterdam & Dublin**.
